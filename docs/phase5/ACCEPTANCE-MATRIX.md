# Phase 5 Integrated Acceptance Matrix (`Core 1 + Core 2`)

Every scenario keeps three evidence levels strictly separated:
- **`unit/contract`**: In-process tests using injectable ports, synthetic fixtures, `@sahaj/gate`, `@sahaj/adapters`, and `@sahaj/api` helpers.
- **`disposable_integrated`**: Throwaway local Postgres 16 cluster (`bootstrap.sql` + all 15 migrations under `infra/supabase/migrations/`), RLS verification, and two-process `@sahaj/atlas` `PostgresSaver` crash/resume.
- **`live`**: Staging/provider execution — intentionally `skipped` (forbidden unless explicitly authorized).

Rules enforced:
- Matrix rows requiring unmerged Phase 2 (`kiro-a`), Phase 3 (`kiro-b`), Phase 4 (`agy-phase4`), or Core 2 (`agy3`) code are explicitly marked **`blocked`** with exact blocking lane(s) — never marked `passed` or silently skipped.
- Counts only — no percentages.
